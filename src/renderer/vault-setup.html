Sicurezza e crittografia

Puoi abilitare la crittografia ora o in qualsiasi momento dalle impostazioni. Con la crittografia attiva, i file vengono cifrati con AES-256-GCM prima di essere scritti su disco.

🔐 Crittografia vault I file .md vengono cifrati con AES-256-GCM + PBKDF2 (310k iterazioni)
⚠️La passphrase non è recuperabile. Se la perdi, i tuoi appunti cifrati saranno inaccessibili. Conservala in un password manager.
